Description
-----------
The Datafile is a text file. Each number is in one line and represents one cube. 
First it varies in the x axis, then in the y axis and finally in the z axis.
In this way, the file would be like:

1   (cube 0,0,0 filled with air)
7   (cube 1,0,0 filled with fat)
15  (cube 2,0,0 filled with hair)
... (after 151 lines...)
12  (cube 0,1,0 filled with cornea)
9   (cube 1,1,0 filled with anterior chamber)
... (after 151x256 lines...)
8   (cube 0,0,1 filled with sclera)
2   (cube 1,0,1 filled with bone)
... (and so on..)
17  (cube 150,256,256 filled with copper - last one)
